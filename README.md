# PixelForge

Простой редактор пиксель-арта на Godot 4.7.2 (C#), заточенный под изометрические постройки rf-game: сетка 2:1, якорь на переднем углу основания, экспорт комплекта видов `<id>.png`, `_winter`, `_turn`, `_turn_winter`.

## Запуск

Нужны .NET SDK 9 и Godot 4.7.2 mono в `C:\Tools\Godot\Godot_v4.7.2-stable_mono_win64\`.

- `run.bat` — собрать C# и открыть редактор.
- Открыть файл сразу: `Godot_v4.7.2-stable_mono_win64.exe --path . -- путь\к\проекту.pforge` (или `.png`).
- Окно на втором мониторе: добавить `--screen 1`.

## Сборка exe

`build.bat` → `build\PixelForge.exe` и папка `build\data_PixelForge_windows_x86_64`: переносить их только вместе. Шаблоны экспорта 4.7.2 mono должны стоять (в `%APPDATA%\Godot\export_templates\4.7.2.stable.mono`).

## Проверка

```
Godot_v4.7.2-stable_mono_win64_console.exe --headless --path . -- --selftest
```

Код возврата 0 — всё в порядке. Тест рисует, отменяет, сохраняет и загружает, экспортирует, гоняет инструменты и холст синтетической мышью и прогоняет реальный эскиз `izba` из rf-game (если папка эскизов на месте). Собранный exe принимает тот же `-- --selftest`.

## Файлы

- `.pforge` — zip: `project.json` (размер, слои с именами, порядком, видимостью, блокировкой, непрозрачностью, подложкой и видами; якорь; W×D; включённые виды; id и папка экспорта; палитра с рампами) и `layers/N.png` по одному на слой. Пишется через временный файл.
- Автосохранение раз в минуту в `<проект>.pforge.autosave` (несохранённый новый проект — в `user://untitled.pforge.autosave`). При открытии предлагается, если оно новее файла; удаляется после сохранения.
- `user://settings.cfg` (`%APPDATA%\Godot\app_userdata\PixelForge`): последние проекты, последняя папка, папки эскизов и экспорта.
- Палитры: `.pal.json` (свой), импорт `.gpl`, `.hex`, PNG.

## Игра

- Клетка основания 18×9 пикселей (тайл 6×3 мировых пикселя × 1.5). Якорь — пиксель переднего угла основания: от него W клеток уходит влево-вверх, D — вправо-вверх (как в `Forge.cs` и `index.json` rf-game). Ширина основания (W+D)×9, высота (W+D)×4.5.
- Проект хранит W×D неповёрнутой постройки; «Основание повёрнутого вида» меняет их местами.
- «Игра → Виды…»: какие слои входят в лето, зиму, поворот и поворот-зиму, какие виды экспортировать. Подложки не экспортируются.
- «Игра → Экспорт для игры…»: обрезает пустые поля, расширяя картинку симметрично, так что якорь — нижний средний пиксель; ниже якоря ничего не остаётся.
- «Игра → Открыть эскиз из rf-game…»: PNG из `art_src\prefab_src` (путь меняется в окне), по `index.json` (`fx`, `fy` — пиксель переднего угла, `w`, `d`) встаёт подложкой с углом на якоре.

## Горячие клавиши

Полный список — F1 в редакторе. Основное: B карандаш, E ластик, G заливка, I/Alt пипетка, L линия (Shift — 2:1), R/O прямоугольник/эллипс, M выделение, A якорь, H/пробел рука, X обмен цветов, [ ] светлее/темнее по рампе, # сетка, Ctrl+Z/Y отмена/возврат, Shift+N новый слой, Ctrl+E слить вниз, Ctrl+Alt+E экспорт для игры.

## Код

- `src/Doc.cs` — документ: слои, отмена (дельты пикселей и снимки списка слоёв), инструменты рисования, выделение, импорт, размер холста, экспорт, `.pforge`.
- `src/CanvasView.cs` — холст: зум, панорама, мышь → инструменты, накладки (сетки, основание, выделение, оси симметрии).
- `src/Main.cs` — окно, меню, панели, горячие клавиши, автосохранение.
- `src/LayersPanel.cs`, `src/PalettePanel.cs`, `src/Palette.cs` — слои и палитра.
- `src/GameDialogs.cs`, `src/Sketch.cs` — виды, экспорт для игры, эскизы rf-game.
- `src/Ui.cs`, `src/Help.cs`, `src/Settings.cs` — диалоги, справка, настройки.
- `src/SelfTest.cs` — самопроверка.
